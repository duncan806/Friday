# Task

Describe the task here. This file is injected only into the user-role agent
and cannot be modified once the cycle starts.

Tasks with a clear surface (a CLI interface, etc.), observable blockages,
and a short build cycle are a good fit. Tasks with a thin surface (pure
algorithms, libraries) are out of scope.

Example (the first experimental task, spec §10): a CLI tool that takes a
CSV file and answers natural-language questions—e.g. from a sales CSV,
"What is the total revenue for March?"
